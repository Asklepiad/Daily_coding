Words frequency counter is an utility for counting the number of unique words or word combinations in the txt file.
In the utilitys point of view word is a sequence of basic latin letters, numbers and "-" symbol. Word combinations are sequences of words, separated by single whitespaces (dot, commas, semicolons and other punctuation marks doesn't allowed).

Original code was written on the Python version 3.9.13 and OS Ubuntu 20.04. There are no additional packages in the requirements.
